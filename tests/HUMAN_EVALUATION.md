# 网站真人式评测用例

本文件用于人工操作伤情与伤残两个网页，并按结构化结果逐项评分。所有输入均为虚构合成资料，不含真实个人病历。

## 评测前准备

1. 在全新浏览器会话中打开目标页面，分别使用伤情页和伤残页；不要点击“保存到本机”。
2. 若本轮评测 Agnes，确认页面后端实际配置为 `agnes-3.0-flash`。当前项目默认后端是 Kimi；只在后端配置 Agnes API Key，不要把 Key 填入前端。
3. 每个用例原样粘贴材料，按用例选择“治疗状态”，点击“开始评估”。等待成功结果或明确错误。
4. 记录页面、模型、请求编号、耗时、结构化事实、状态、等级、条款和错误。不要只凭总结语句评分。

## 评分口径

- 8 个用例共 100 分。每个用例可按其“计分点”部分给分；只给满足全部描述条件的单项分值。
- 事实命中要求字段和值正确，且证据能在输入原文中回查。输入没有写明的事实属于多报。
- 等级、状态、条款编号按预期结果核对；总结和推理允许措辞不同，不按文本相似度计分。
- `准确率（已完成样本）= 已得分 ÷ 已完成样本满分 × 100%`。接口超时或错误不混入语义准确率，另记为“接口覆盖率 = 成功返回结果数 ÷ 8”；不可把失败请求伪装成模型准确率。
- 同时报告逐用例分数和总分。该分数只代表本文件合成案例的命中率，不代表真实病例临床或司法鉴定准确率。

## 用例

### T01：两处肋骨骨折，检查处数与肋骨根数

- 页面：伤情程度评估
- 表单：治疗状态“治疗终结或稳定”
- 输入：

  > 合成资料，非真实病例。2025年4月12日急诊CT报告明确记载：本次事故后左侧第3肋骨有1处骨折线，左侧第4肋骨有1处骨折线，共2处骨折。既往没有肋骨损伤，治疗已终结，病情稳定。

- 预期输出：`status=preliminary`；`grade=轻伤二级`；引用 `5.6.4.b`（肋骨骨折2处以上）。事实至少区分左侧、第3与第4肋骨、2根肋骨、2处骨折；不能把“2根肋骨”当成“2处骨折”的证据。等级条件证据须能回查“共2处骨折”。
- 计分点（20分）：肋骨骨折与左侧正确（4）；肋骨序号 `[3,4]` 与肋骨根数 `2` 正确（4）；骨折处数 `2` 且证据可回查（4）；状态、等级与条款三者均正确（8）。

### T02：一根肋骨一处骨折

- 页面：伤情程度评估
- 表单：治疗状态“治疗终结或稳定”
- 输入：

  > 合成资料，非真实病例。2025年4月12日影像报告明确记载：本次事故后右侧第8肋骨有1处骨折线，共1处骨折。治疗已终结，病情稳定。

- 预期输出：`status=preliminary`；`grade=轻微伤`；条款 `5.6.5.a`。应记录右侧、第8肋骨、1处骨折；不能把本用例判为“无损伤”。
- 计分点（10分）：部位、侧别、序号和处数正确（4）；状态、轻微伤等级及条款正确（6）。

### T03：否定骨折与阳性挫伤并存

- 页面：伤情程度评估
- 表单：治疗状态“尚不明确”
- 输入：

  > 合成资料，非真实病例。CT报告：未见左侧第6肋骨骨折；另见左肩软组织挫伤。

- 预期输出：肋骨骨折不得作为阳性事实；若输出该事实，确定性应为 `excluded`。左肩软组织挫伤可作为已报告事实。`grade=null`，不得仅凭挫伤词语给出肋骨骨折等级。
- 计分点（10分）：否定作用域准确，且未把“未见骨折”变成阳性（5）；挫伤与骨折分开，并且没有无依据等级（5）。

### T04：考虑诊断不等于确诊

- 页面：伤情程度评估
- 表单：治疗状态“尚不明确”
- 输入：

  > 合成资料，非真实病例。影像报告提示“考虑左侧第6肋骨骨折”，建议复查；目前没有复查结果，也没有明确确诊记录。

- 预期输出：骨折事实若出现，确定性为 `uncertain`，证据包含“考虑”或“建议复查”；`grade=null`，状态为材料不足或需复核，不能输出轻伤等级。
- 计分点（10分）：保留不确定性和原文依据（5）；没有将其升级为确诊或输出等级（5）。

### T05：同一事件的相互矛盾报告

- 页面：伤情程度评估
- 表单：治疗状态“尚不明确”
- 输入：

  > 合成资料，非真实病例。2025年4月12日同一次事故。急诊CT报告明确记载左侧第6肋骨骨折；同日复核报告记载未见左侧第6肋骨骨折。两份报告针对同一次受伤。

- 预期输出：`status=needs_review`、`requiresReview=true`、`grade=null`。冲突两端必须能对应到相反报告事实；不能任选一个报告给等级。
- 计分点（15分）：识别同一事件的相反事实并标记冲突（8）；需复核且不输出等级（7）。

### T06：既往伤与本次伤分开

- 页面：伤情程度评估
- 表单：治疗状态“治疗终结或稳定”
- 输入：

  > 合成资料，非真实病例。既往史：2020年左侧第6肋骨骨折，现已愈合。现病史：2025年本次事故后，CT明确记载右侧第8肋骨1处骨折线，共1处。

- 预期输出：2020年的左侧骨折归为 `prior_injury` 或明确既往事实；2025年的右侧第8肋骨骨折归为本次 `injury_type`。不能将左侧旧伤并入本次右侧序号或骨折处数。当前一处肋骨骨折可对照 `5.6.5.a`，预期 `轻微伤`。
- 计分点（15分）：时间、既往/本次及左右侧归属均正确（8）；本次状态、等级及条款正确（7）。

### T07：伤残评估仍在治疗中

- 页面：伤残等级评估
- 表单：治疗状态“治疗中”
- 输入：

  > 合成资料，非真实病例。成年人因本次事故接受脾部分切除术，目前仍在治疗，尚无治疗终结或临床效果稳定记录，也没有完整复查资料。

- 预期输出：可抽取“脾部分切除术”事实，但 `grade=null`、不得输出伤残等级；状态应为材料不足或需复核，并提示治疗时机或稳定情况仍需核实。
- 计分点（10分）：手术事实可回查（4）；治疗中的门控有效，不输出伤残等级（6）。

### T08：伤残评估术后稳定的标准命中

- 页面：伤残等级评估
- 表单：治疗状态“治疗终结或稳定”
- 输入：

  > 合成资料，非真实病例。成年人因本次事故接受脾部分切除术。出院记录和手术记录一致，治疗已终结，临床效果稳定；记录明确说明手术由本次事故导致。

- 预期输出基准：事实为“脾部分切除术后”；按《人体损伤致残程度分级》`5.9.4.2`，预期 `status=preliminary`、`grade=九级伤残`，条款证据可回查到手术记录。
- 计分点（10分）：手术事实与证据正确（4）；状态、九级伤残和 `5.9.4.2` 均命中（6）。
- 标准逻辑：本地将“脾部分切除术后”映射到可回查的手术事实；治疗仍在进行时不得输出等级，治疗终结或临床效果稳定后再对照本条。
