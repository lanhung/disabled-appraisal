# 部署版代码 + 2026-11-18 修复

本目录不是仓库主线的开发源码（主线仍是 2026-10 的版本），而是**线上 5090 部署实例实际运行的代码**（release 20261103-vllm-9b），外加 2026-11-18 的四处修复。

## 为什么这样放
部署版比仓库主线新（核心文件 18 个 vs 8 个），直接覆盖会丢掉主线的源码、测试和前端工程。因此放在独立目录，便于逐文件比对。

## 目录
- `code/gemini/` 后端源码（无 node_modules；`.env.example` 为占位，真实钥匙未入库）
- `code/dist/` 前端构建产物（两个站点）
- `code/deploy/` 部署脚本
- `patches/` 相对部署版的四处改动（统一差异，共 163 行含上下文）
- `baseline_lib/` 改动前的四个原文件
- `修改说明.md` 改了什么、为什么改、怎么应用
- `验证结果.md` 50 条真实案例的前后对比

## 应用方式
将 `code/gemini/lib/` 下 `assessment.js`、`condition-logic.js`、`results.js`、`facts.js` 复制到部署目录同名位置，重启后端即可；前端、标准库、模型配置均无需改动。
